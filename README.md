# Steel Yield Strength Prediction using Random Forest and Explainable AI (SHAP)

## Overview

This project predicts the yield strength of steel alloys using Machine Learning. A Random Forest Regressor is trained on material composition and processing parameters, while SHAP (SHapley Additive exPlanations) is used to interpret model predictions and identify the most influential features.

---

## Objectives

- Predict steel yield strength accurately
- Compare predicted and actual values
- Interpret model decisions using Explainable AI (SHAP)
- Identify the most influential material properties

---

## Features

- Data Cleaning
- Exploratory Data Analysis (EDA)

- Explainable AI with SHAP

## Results

The Random Forest model provides accurate yield strength predictions, while SHAP explains how each feature contributes to individual predictions, making the model more transparent and interpretable.
